# Оптимизация клиент-серверных приложений

## Учебный курс

Дисциплина: **Оптимизация клиент-серверных приложений**

Направление подготовки: **09.03.02 «Информационные системы и технологии»**

Профиль: **Информационные системы и технологии управления технологическими процессами**

Уровень образования: **бакалавриат**

---

## О курсе

В рамках дисциплины изучаются основные принципы построения, взаимодействия и оптимизации клиент-серверных приложений.

Практическая часть курса построена вокруг разработки небольшого веб-приложения.

Студенты последовательно изучают:

* HTML;
* CSS;
* JavaScript;
* DOM;
* формы и валидацию;
* Fetch API;
* PHP;
* HTTP-взаимодействие;
* GET и POST;
* MySQL;
* SQL;
* CRUD;
* проектирование структуры базы данных;
* оптимизацию SQL-запросов;
* оптимизацию PHP;
* оптимизацию JavaScript;
* основы безопасности;
* комплексную оптимизацию приложения;
* Git и GitHub.

---

## Основной проект

В течение курса каждый студент разрабатывает и постепенно совершенствует собственное клиент-серверное веб-приложение.

Базовый вариант проекта:

> **Веб-система обработки заявок**

Приложение должно позволять пользователю:

* просматривать заявки;
* создавать заявки;
* редактировать заявки;
* удалять заявки;
* искать заявки;
* фильтровать заявки;
* изменять статус заявки.

Студент также может получить индивидуальную предметную область согласно назначенному варианту.

# Основные требования

Каждый студент работает в индивидуальном GitHub repository.

После выполнения каждой лабораторной работы необходимо:

1. выполнить задание;
2. протестировать результат;
3. сохранить изменения в Git;
4. выполнить commit;
5. выполнить push в GitHub;
6. оформить краткий отчёт;
7. добавить необходимые скриншоты.
